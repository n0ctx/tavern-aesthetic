# 按需素材来源

仅在当前页面确实需要额外素材时读取。先检查项目已有资产；再针对缺口选择 1～2 个来源，少量检索。不要为了逐个访问这里的网站而耗费时间。

| 来源 | 适用素材 | 使用要点 |
| --- | --- | --- |
| [Kenney](https://kenney.nl/assets) | 游戏 UI 图形包、按钮、游戏通用素材 | 其资产页面的游戏素材通常为 CC0；以目标资产页及压缩包许可为准。 |
| [Game-icons.net](https://game-icons.net/) | 技能、状态、道具、武器图标（SVG） | 多数为 CC BY 3.0，须保留相应作者署名；个别为公有领域，逐项核对。 |
| [Poly Haven Textures](https://polyhaven.com/textures) | 金属、纸面感、石材、墙面等纹理 | 站内自有资产为 CC0；按需用低分辨率版本，避免无意义的 4K/8K 贴图。 |
| [Unsplash](https://unsplash.com/) | 现实题材场景、摄影背景和物件照片 | 免费图片可按 Unsplash License 使用；注意独立商标、人物肖像等额外权利，区分付费 Unsplash+。 |
| [Google Fonts](https://fonts.google.com/) | 中文及英文字体 | 按实际字体查看许可证和中文字形覆盖。中文字体较大，注意加载量与后备字体。 |
| [Openverse](https://openverse.org/) | 搜索开放许可图片 | 聚合搜索不是统一授权；逐项查看原站与许可证、署名或相同方式共享要求。 |

## 选用和落地

1. 先按**视觉需求**找素材：需要什么主体、年代感、线条复杂度、配色与材质；不要先下载再强行适配。
2. 核实具体文件的来源、许可及必要署名，不把搜索预览图当作可随意使用的原素材；遇到不确定许可就放弃。
3. 按用途裁切、压缩、调色、统一清晰度与光影，并保存到项目现有资产路径；避免第三方临时 URL 热链。
4. 优先使用 WebP、SVG 等合适格式；避免大图填满小图标位。授权需要署名时在项目既有说明或简短素材说明中记录。
5. 找不到匹配的通用素材时，可按主 Skill 的规则考虑现有 AI 生图工具制作独特核心美术资产；没有生图能力则使用现有资源与合适的 CSS/SVG，不杜撰已获取或生成的素材。
